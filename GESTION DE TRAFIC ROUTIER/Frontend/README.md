# Gestion de Trafic Routier - Frontend (VolcanWay)

Ce dossier contient l'interface utilisateur (Frontend) pour le projet de Gestion de Trafic Routier (VolcanWay).

## Technologies Utilisées
- React
- TypeScript
- Vite

## Prérequis
Assurez-vous d'avoir [Node.js](https://nodejs.org/) installé sur votre machine.

## Installation et Démarrage

1. Installer les dépendances :
   ```bash
   npm install
   ```

2. Démarrer le serveur de développement :
   ```bash
   npm run dev
   ```
   L'application sera accessible localement (généralement sur `http://localhost:5173`).

## Structure et Fonctionnalités
- **Interface interactive** pour visualiser le trafic dans le quartier "Les Volcans" (Goma).
- **Signalement d'incidents** (accidents, travaux, embouteillages).
- **Tableau de bord (Dashboard)** avec des statistiques en temps réel.
- **Responsive Design** avec une approche "Mobile-First".
